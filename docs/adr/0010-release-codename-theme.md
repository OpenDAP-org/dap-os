# ADR 0010: Release codename theme

- **Status:** Superseded by [ADR 0011](0011-blackbird-os.md)
- **Date:** 2026-10-22

## Context

Each OpenDAP OS release carries a public codename, and the first is Blackbird ([ADR 0009](0009-release-codenames.md)). How the following codenames are chosen was open.

## Decision

Release codenames follow one theme: **experimental and reconnaissance aircraft**, such as the X-15 or the U-2. Each release picks its name from that theme when it is planned.
