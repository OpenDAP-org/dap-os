# OpenDAP OS

OpenDAP OS, the operating system of the OpenDAP T1: image build, per-SKU profiles and releases.

## Layout

- `build/` — build VM (Lima), image build and virtual T1 scripts
- `image/`
- `overlays/`
- `docs/`
